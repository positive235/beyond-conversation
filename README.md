## Tech Stack
- Frontend: Next.js, React.js, TypeScript, Tailwind CSS
- Backend: Node.js, Express, WebSocket server
- AI: OpenAI Realtime API 

## How to Run
- backend: 
    ```
    cd backend
    npm run dev
    ```
- frontend:
    ```
    cd frontend
    npm run dev
    ```

- Open: `http://localhost:3000`
